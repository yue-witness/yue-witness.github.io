《冬日削土豆模拟器》隐私政策

版本 3 · 生效日期：2026 年 11 月 11 日 · 开发者：个人开发者潘越（发行署名“血月的工作室”）

《冬日削土豆模拟器》（以下简称“本游戏”）由个人开发者潘越（发行署名“血月的工作室”，以下简称“我们”）开发和运营。我们非常重视你的隐私。本政策说明本游戏会在你的设备上保存哪些数据、不会做什么、TapTap 安卓版接入的第三方 SDK 会处理哪些信息，以及你可以如何管理这些数据。

本游戏有三个版本：TapTap 安卓版（包名 com.xueyue.potatopeel）、微信小游戏版和网页版。除第三部分“第三方 SDK”只适用于 TapTap 安卓版外，本政策适用于全部版本。

一、我们自己不收集你的个人信息

  • 微信小游戏版和网页版是单机游戏，不需要注册、登录或实名认证。TapTap 安卓版需要用 TapTap 账号登录才能进入游戏（见第三部分），授权由 TapTap 完成。无论哪个版本，本游戏都不会要求你提供姓名、手机号、身份证号、邮箱等个人信息。
  • 除 TapTap 安卓版提交到 TapTap 排行榜的通关用时（见第三部分）外，本游戏不会把你的游戏数据上传到我们或任何第三方的服务器。我们没有用于接收玩家数据的服务器，也收不到第三方 SDK 处理的信息；作为游戏开发者，我们可能在 TapTap 开发者后台看到排行榜上的成绩和对应的 TapTap 昵称。
  • 本游戏自己的程序不读取设备标识（如 IMEI、Android ID、OAID、MAC 地址）、位置、通讯录、短信、相册、麦克风、摄像头或已安装应用列表，也不读取你的剪贴板；TapTap 安卓版也不读取、不保存你的 TapTap 昵称、头像和账号标识（游戏程序只判断是否已登录）。
  • 微信小游戏版和网页版没有接入任何第三方 SDK；TapTap 安卓版接入了 TapADN 广告 SDK 和 TapSDK（TapTap 登录、排行榜，见第三部分），没有统计、支付、推送 SDK（TapSDK 自带的数据统计功能我们已关闭）。

二、保存在你设备上的数据

为了让游戏能继续上次的进度，本游戏会在你设备的本地存储里保存以下数据：

  • 游戏存档：进度、金钱、已申领的物品、已读的剧情、看过的结局和个人最佳成绩等；
  • 设置：音量、震动、灵敏度、左手模式、画质，以及是否跳过新手引导；
  • 游戏内统计：每局用时、削皮次数、各阶段耗时、削皮手感等游戏事件记录，只用于设置里的“导出埋点 JSON”和本机的结算页；
  • 你同意本政策的记录：同意的版本号和时间，用于判断以后是否需要再次请你确认；
  • 待提交的通关用时（仅 TapTap 安卓版）：通关后暂存在本机，提交到 TapTap 排行榜成功后清除，没交上时下次启动再试。

除上面说明的通关用时外，这些数据只保存在你的设备上（网页版在浏览器的本地存储里，Android 版在应用的私有目录里，微信小游戏版在微信为本游戏分配的本地缓存里），不会上传，也不会被我们看到。

三、第三方 SDK（仅 TapTap 安卓版）

TapTap 安卓版接入了下面两个第三方 SDK，分别用于播放激励视频广告和 TapTap 登录、排行榜。它们只在你点击【同意并进入】同意本政策之后才会初始化；你同意之前，本游戏不会初始化它们，也不会联网。

TapADN 广告 SDK（Dirichlet）

  • SDK 名称与版本：TapADN（Dirichlet）Android 广告 SDK 5.3.2.0（包名 com.tapsdk.tapad，依赖开源网络库 OkHttp 3.10.0）
  • 提供方：上海艾得蒽数字科技有限公司及其关联方（TapTap 广告联盟）
  • 使用场景：部分装备申领、技能学习，以及急单失败后的“看广告免罚”，在你确认【观看广告】后加载并播放激励视频广告；看完后该次操作生效。暂时没有可播放的广告时，游戏会提示并直接生效
  • 处理目的：广告投放、广告监测归因、统计分析、反作弊，以及保障网络服务和 SDK 稳定运行（据提供方说明）
  • 处理的信息：设备基础信息（品牌、型号、系统版本等）、网络信息（网络状态、信号强度、IP 地址）、应用信息（应用包名、版本号、进程信息、前后台状态）、广告的展示 / 点击 / 转化等交互信息、崩溃与性能数据；设备 DRM 标识（用于反作弊与去重）。具体以提供方隐私政策为准
  • 我们关闭的可选采集：位置、电话状态（含设备序列号）、Wi-Fi 信息（含 SSID / BSSID）、MAC 地址、传感器（含摇一摇广告互动）、外部存储、已安装应用列表、Android ID 与 OAID
  • 处理方式：SDK 自行采集，直接发送给提供方；我们收不到这些信息
  • 提供方隐私政策：https://ssp.dirichlet.cn/docs/agreement/
  • 合规说明：https://ssp.dirichlet.cn/docs/compliance/

TapSDK（TapTap 登录、排行榜）

  • SDK 名称与版本：TapSDK Android 4.11.1（登录模块 tap-login、排行榜模块 tap-leaderboard，包名 com.taptap.sdk）
  • 提供方：易玩（上海）网络科技有限公司（TapTap）
  • 使用场景：点【登录游戏】后用 TapTap 账号登录（已经登录过的不再弹出授权）；通关后把通关用时提交到 TapTap 排行榜。游戏内没有排行榜界面，排行榜只在 TapTap 内展示
  • 处理目的：账号登录与授权、排行榜成绩的提交和展示，以及确保设备系统兼容、定位解决问题（据提供方说明）
  • 处理的信息：你的 TapTap 账号标识（openid、unionid）、TapTap 昵称和头像（你授权时由 TapTap 提供）、提交的通关用时（有效游戏时间）；系统版本、设备型号、设备 CPU 信息、网络类型、设备内存信息（每次启动或授权时）、Android ID（SDK 初始化和发起授权时），均据提供方说明。具体以提供方隐私政策为准
  • 我们关闭的功能：TapSDK 自带的数据统计（TapDB，已关闭，不上报游戏事件）；排行榜的分享功能（不使用，已移除存储权限）
  • 处理方式：SDK 自行采集，直接发送给提供方。你的通关用时由 TapTap 保存，并在 TapTap 的排行榜上和你的 TapTap 昵称、头像一起展示
  • 提供方隐私政策：https://www.taptap.cn/doc/privacy-policy/
  • TapSDK 隐私说明与合规说明：https://developer.taptap.cn/docs/sdk/start/agreement/ 、https://developer.taptap.cn/docs/sdk/start/compliance/

此外，TapTap 安卓版还包含 AndroidX 支持库（如 androidx.webkit，Google 提供的开源组件，只用于在应用内显示游戏画面）和 TapSDK 依赖的开源组件（Kotlin 标准库、Glide、Retrofit 等），这些组件本身不收集个人信息。

四、联网与权限说明

  • TapTap 安卓版申请的权限只有三项，都是安装时自动授予、不会弹窗的普通权限：网络（INTERNET，供广告 SDK 加载和播放广告、TapSDK 登录和提交成绩）、网络状态（ACCESS_NETWORK_STATE，第三方 SDK 判断是否联网）、震动（VIBRATE，游戏手感）。我们移除了广告 SDK 自带的安装应用、查询全部已安装应用、OAID 等权限，以及排行榜模块自带的存储权限。游戏画面和存档本身不联网。
  • 网页版需要从托管网页的服务器下载游戏本身的程序、图片和字体；微信小游戏版由微信下载游戏包和资源分包。这些都只是下载游戏文件，不包含你的任何数据。托管服务器或平台可能按其自身规则记录访问日志（如 IP 地址、访问时间），这部分由对应平台按其隐私政策处理。
  • 如果你通过微信、TapTap 等平台打开本游戏，平台本身对你信息的处理适用平台自己的隐私政策。

五、设备功能的使用

  • 震动：削皮、盖章等操作时手机轻震，用于游戏手感，不涉及个人信息；可以在“设置”中关闭。
  • 声音：游戏的音效和音乐都由程序在本机合成播放，不会使用麦克风，也不会录音。
  • 剪贴板：只有在你主动点击“设置 → 导出埋点 JSON”时，游戏才会把本机的游戏统计写入剪贴板，方便你自己保存或反馈问题；游戏不会读取剪贴板。

六、你如何管理这些数据

  • 在游戏“设置”中，你可以导出本机的游戏统计（导出埋点 JSON）、重置存档、恢复默认设置。
  • 清除浏览器的网站数据、在系统设置中清除本游戏的应用数据、卸载本游戏或删除小游戏，都会删除上述全部数据。
  • 因为我们不持有你的任何数据，所以无法替你查询、更正或恢复；你可以直接在设备上管理。对第三方 SDK 处理的信息和 TapTap 排行榜上的成绩，你可以依据提供方的隐私政策向提供方行使查询、更正、删除等权利（TapTap 的联系方式：privacy@taptap.com）。
  • 你可以拒绝本政策（此时无法开始游戏）；也可以在系统设置中清除本游戏的数据或卸载本游戏，之后第三方 SDK 不会再处理你的信息。

七、未成年人保护

我们不会主动收集任何人的个人信息，包括未成年人的个人信息；本游戏没有任何付费内容。未满 14 周岁的未成年人应在监护人阅读并同意本政策后使用本游戏。请未成年人在监护人的指导下合理安排游戏时间。

八、广告

本游戏部分装备申领、技能学习以及急单失败后的“看广告免罚”设计为“观看激励视频后生效”。每次播放前都会先弹窗询问，是否观看由你自己决定；选择不看或中途关闭，这次操作会撤回，花掉的钱或技能点原样退回：

  • TapTap 安卓版：播放 TapADN 提供的真实激励视频广告（见第三部分）。广告由提供方投放，我们不控制具体广告内容；广告里的链接、下载或购买由对应的广告主负责。
  • 网页版：显示的是模拟广告画面，不联网、不处理任何信息。
  • 微信小游戏版：目前没有接入广告，按“广告加载失败”处理，直接生效。

暂时没有可播放的广告、广告加载失败时，游戏会提示并直接生效。

九、政策的更新

如果本政策发生变化（例如接入新的 SDK），我们会提高本政策的版本号，并在你下次进入游戏时再次请你阅读和确认。
