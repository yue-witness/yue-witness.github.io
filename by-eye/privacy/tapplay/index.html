《目测》隐私政策（TapTap 版）

更新日期：2026 年 11 月 8 日

本政策适用于在 TapTap 发行的安卓游戏《目测》（包名 com.byeye.trial，以下称“本游戏”），由独立开发者“By Eye”（以下称“我们”）开发。本政策说明本游戏处理哪些信息、为什么处理，以及接入的第三方 SDK。

一、同意在先

首次启动时，本游戏会先展示隐私政策弹窗。在你点击“同意”之前，本游戏不会初始化任何广告 SDK，也不会发起广告请求。TapTap 登录需要你另外点击“TapTap 登录”并在 TapTap 授权页确认后才会进行。

二、保存在你设备上的信息

本游戏在应用私有存储中保存关卡进度、星数、无尽模式记录、设置（音乐与音效音量、字号、语言）以及用于生成题目的随机数。我们不运营自己的服务器，不会收集或接收这些数据。你可以在系统设置中清除本游戏的存储或卸载本游戏来删除它们。

本游戏不申请通讯录、相机、麦克风、定位、照片或文件等权限。安装包中已移除广告 SDK 自带的定位、电话状态、存储、Wi-Fi 状态与应用列表等权限声明。

三、接入的第三方 SDK

1. TapTap SDK（登录、排行榜、云存档）

  • 提供方：易玩（上海）网络科技有限公司
  • 用途：TapTap 账号登录与游戏测试资格验证；无尽模式排行榜（含好友榜）；云存档。
  • 处理的信息：TapTap 账号标识、昵称与头像、登录所需的设备与网络信息；排行榜成绩（无尽模式通过的关卡数与星数）；在 TapTap 内读取的好友关系（仅用于生成好友榜，本游戏不保存）；云存档内容（已通关关卡的最高星数与无尽模式最佳成绩）。
  • 隐私政策：https://www.taptap.cn/doc/privacy-policy/

2. TapADN 广告 SDK（Dirichlet）

  • 提供方：上海艾得蒽数字科技有限公司
  • 用途：在关卡结算时展示插屏广告，用于广告投放、监测归因、统计分析与反作弊。
  • 处理的信息：设备基础信息（品牌、型号、系统版本、屏幕密度与分辨率、语言、时区、CPU 信息、可用存储空间）、网络状态与信号强度、IP 地址、应用包名 / 版本号 / 前后台状态与运行中的进程信息、广告展示与点击等交互信息、崩溃与性能数据。
  • 隐私政策：https://ssp.dirichlet.cn/docs/agreement/

我们在初始化广告 SDK 时关闭了可选信息的获取：位置、电话状态（含设备序列号）、Wi-Fi 信息（含 SSID / BSSID）、MAC 地址、传感器、外部存储、已安装应用列表、Android ID 与 OAID，并关闭了摇一摇广告交互。广告 SDK 仍可能依据其隐私政策处理其列为必要的信息；这些信息由提供方直接处理，我们不会收到。

四、未成年人

我们不会主动收集未成年人的个人信息。未满 14 周岁的未成年人应在监护人阅读并同意本政策后使用本游戏。

五、共享与保存期限

我们自己不出售、不共享任何个人信息，也不会收到上文所述数据。除上文列出的第三方 SDK 处理的信息外，没有数据离开你的设备。设备上的数据保存至你删除为止；TapTap 云存档可通过 TapTap 账号相关功能管理。

六、你的选择

你可以拒绝隐私政策（此时无法开始游戏），可以不登录 TapTap，也可以在系统设置中清除本游戏数据或卸载本游戏。对第三方 SDK 处理的信息，可依据其隐私政策向提供方行使权利。

七、政策变更

如本游戏处理信息的方式发生变化，我们会更新本政策及上方的更新日期；接入新的 SDK 时会在游戏内重新征得同意。
